Geo-agnostic software for real-time spatial data processing and analysis on scalable, auto-scaling platforms.

## Technology Stack

- python

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/OutlineCatchment.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

OutlineCatchment is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
